## About Me
Hello! I'm **Myint Myat Pyae Sone**, a passionate software engineering student and tech enthusiast from Myanmar. </br>
</br>I’m currently diving into DevOps, focusing on **Linux** through the Introduction to Linux course by the Linux Foundation. Alongside that, I’m studying CI/CD with **GitLab** and **Kubernetes**, having already completed **Docker** and **Docker Compose**. I'm also preparing to earn the **AWS Certified Solutions Architect – Associate certification**. </br>
</br>I also have a strong foundation in **Java** and I'm expanding my skills with **Spring Boot** and improving my code quality with **SOLID** principle and **Design Patterns** to teach myself how to write concise and clean code.

I’ve worked on projects like a **CashNex Java EE banking system** and am exploring **FullStack development** using the **MERN stack**.  
I’m passionate about contributing to **open-source projects** and continuously learning. </br>
</br>Feel free to check out my repositories and connect!
